## 二、页面 / 场景变化（相对第 1 期）

- **Kind 右栏换身份**：第 1 期「在做的事」（每项目一条地铁线）→ 第 2 期上「聚焦」+ 下「Kind 现在带着」；原线路图挪到工作页。
- **新增场景**：`#now`、`#work`（看板 \| 等你）、`#task:<id>`、`#trace:<id>`（单独场景，避免同场景换路由不刷新）、`#project:<id>`（项目页 \| 对话）、`#read:<文件名>`（目录 / 原件 / 伴读）。
- **#empty:now** 空态；**#ability** 新增「内置流程」三档分组，「新建流程 → 模板」也列三档。
- **信息分层**：底栏只留模型名（占用/花费悬停出）；「工作过程」默认只显示用时；成果卡收成「改了什么 N 处 · 要求 x/y 满足」。
- **修复第 1 期两处静默问题**：toast 没挂 Toaster、sonner 颜色 token 名不对；**旧布局存档**（面板 id 变过）自动弃用回默认布局。
- **用户指出的回归**（12:50）：「Kind 现在带着」丢了 v13 的块色（9px 色标 + 分色比例条），已按 v13 的 `--kf-c1..8` 深/浅两套补回（`ed3458e`）。
